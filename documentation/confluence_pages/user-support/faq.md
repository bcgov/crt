# Frequently Asked Questions (FAQ)

Users with these queries (see below) should be able to find their answers in this section.

## I am using Internet explorer and the application screens are not showing up properly?

The CRT application's front end uses components that are not compatible with Internet Explorer, this is also true for the Transportation Web Map (TWM) used for adding and viewing project segments.

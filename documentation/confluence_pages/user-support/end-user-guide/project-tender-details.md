# 3.6 Project Tender Details

This section is used to record tender details for the project.

## Getting to project tender details

- Refer to [Navigation → Project Information](https://moti-imb.atlassian.net/wiki/display/CRPDB/2+Application+components#id-2Applicationcomponents-ProjectInformation) to see how to navigate to various sections of the application.

## Adding a tender

User can add a tender in one of two ways:

### Add Function

- Click the add (+) button on the top right of the section.

<!-- IMAGE: Add tender button -->

- Fill in the details in the form that appears and save (Submit) the information.

<!-- IMAGE: Add tender form -->

### Clone Function

At least one row needs to exist for the user to be able to use the clone feature.

- Click the clone button on the right of the row to be cloned.

<!-- IMAGE: Clone button -->

- Update the details in the form that appears and save (Submit) the information.

<!-- IMAGE: Clone form -->

## Edit tender

- Click the edit (pencil) button on the right of the row to be updated.

<!-- IMAGE: Edit button -->

- Update the details in the form that appears and save (Submit) the information.

<!-- IMAGE: Edit form -->

## Delete tender

- Click the delete (trash) button on the right of the row to be deleted.

<!-- IMAGE: Delete button -->

- Confirm the action to delete the row.

<!-- IMAGE: Delete confirmation -->

# 1 Using this guide

This document is intended to provide user's an overview of the capabilities and features of the application. It will provide some guidelines on how to integrate the features into the business processes.

## Key terms

Please make note of the following terms in the document, these are commonly used throughout the document. Various sections may have additional terminology not covered below, these terms will be described in their corresponding sections of the guide.

| Term | Reference |
|------|-----------|
| System/CaRT/CRT/Application/Tool | Capital and Rehabilitation Tracking application |
| User | Any individual that may be granted access to CaRT |
| Data entry | The process of data collection and/or input by the CaRT users for one or more sections of the application |
| Staff | MoTI individual(s) directly / indirectly associated with CaRT, they may/may not be application users |
| UAT | User acceptance testing environment that the users can use for validation testing/training |
| PRD/Production/Live | The production instance of the application that will be in user for day-to-day data entry |

## Accessing the user's guide

### From Confluence

- The simplest way to access this guide would be through Confluence - [CRT End User's Guide](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302666)

### Exporting the end user's guide

Any staff personnel with access to this space can export this section, or parts of this section, from the confluence space - to make it available to others.

1. Open "Space Tools" → "Content Tools" on the bottom left corner of the confluence space.

<!-- IMAGE: Space Tools location -->
<!-- IMAGE: Content Tools -->

2. From within "Content Tools" go to "Export" tab.

<!-- IMAGE: Export tab -->

3. Select the "Export Format", users can select from HTML/XML/PDF (for this example we will use PDF), and then click "Next>>".

<!-- IMAGE: Export format selection -->

4. User can select Normal Export - to generate an export for the entire confluence space, Custom Export - to select specific sections of the CaRT confluence space.

<!-- IMAGE: Export type selection -->

5. To export the user's guide select custom export, and select the user's guide section (or specific sections from within the user's guide).

<!-- IMAGE: Page selection for export -->

6. Click "Export" at the bottom of the page (users can choose to include page numbers as well).

<!-- IMAGE: Export button -->

7. Once the export has been generated click on "Download <format>" (in this case the format is PDF) link to save the export to the desktop.

<!-- IMAGE: Download link -->

## Other notes

- The screenshots and the functionality description used in this manual are consistent with what the users should experience while using the application on **Microsoft Edge** web browser. The application should perform to fulfill user needs on other common browsers as well, such as Google Chrome, and Mozilla Firefox. However, note the user experience on Internet Explorer (IE) is NOT optimal, and some features do not work with IE.
- While learning this application it is recommended that the user has access to the user acceptance testing (UAT) environment - https://uat-crt.th.gov.bc.ca/ - refer to this document and follow along in the UAT instance of the application to get a better understanding of various screens and functions.
- The actual data entry will be performed in the production environment - https://crt.th.gov.bc.ca/
- The document is being designed using a Production ready version of user acceptance testing environment.
- Kindly keep in mind that the manual only describes the various components and features of this application. It is assumed that at the time of consulting this document the user has knowledge of the program and its processes.

While going through the document, please provide feedback to the project team and/or System Administrator(s) if anything is amiss.

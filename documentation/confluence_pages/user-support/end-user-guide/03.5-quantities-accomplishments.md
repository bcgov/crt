# 3.5 Quantities/Accomplishments

This section is used to record financial plan for the project, by fiscal year.

## Getting to quantities/accomplishments

- Refer to [Navigation → Project Information](https://moti-imb.atlassian.net/wiki/display/CRPDB/2+Application+components#id-2Applicationcomponents-ProjectInformation) to see how to navigate to various sections of the application.

## Adding a quantity/accomplishment

User can add a quantity/accomplishment in one of two ways:

### Add Function

- Click the add button on the top right of the section.
- Select whether to add a quantity or an accomplishment.

<!-- IMAGE: Select quantity or accomplishment -->

- **Adding a quantity** - select quantity, provide the necessary details and save (Submit) the information.

<!-- IMAGE: Add quantity form -->

- **Adding an accomplishment** - select accomplishment, provide the necessary details and save (Submit) the information.

<!-- IMAGE: Add accomplishment form -->

### Clone Function

At least one row needs to exist for the user to be able to use the clone feature. The clone can only be used to create similar entities, i.e. only a new quantity can be created if the row being cloned is a quantity.

- Click the clone button on the right of the row to be cloned.

<!-- IMAGE: Clone button -->

- Update the details in the form that appears and save (Submit) the information.

<!-- IMAGE: Clone form -->

## Edit quantity/accomplishment

- Click the edit (pencil) button on the right of the row to be updated.

<!-- IMAGE: Edit button -->

- Update the details in the form that appears and save (Submit) the information.

<!-- IMAGE: Edit form -->

## Delete quantity/accomplishment

- Click the delete (trash) button on the right of the row to be deleted.

<!-- IMAGE: Delete button -->

- Confirm the action to delete the row.

<!-- IMAGE: Delete confirmation -->

## Filter quantity/accomplishment

Users can filter the data for quantity and accomplishment by the type of data (whether quantity or accomplishment) and/or fiscal year.

### Quantity/Accomplishment

- To see the rows by the type of data (quantity/accomplishment), select a value from the drop down.

<!-- IMAGE: Type filter dropdown -->

- Only the data corresponding to the selected type will be displayed.

<!-- IMAGE: Filtered by type -->

### Fiscal Years

- Users can filter by fiscal year to see data for a specific period.

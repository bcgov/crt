# 3 Project data entry

## New Project

Users can create project via the *Add Project* button on the project search screen.

<!-- IMAGE: Add Project button on search screen -->

Then provide the relevant details on the *Add Project* form that pops up. Some fields are required to create a new project.

<!-- IMAGE: Add Project form -->

## Adding/Editing project information

Once a project has been created, further details can be added to the following sections:

- [3.1 Project Details](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302892/3.1+Project+Details)
- [3.2 Status and EMR Comments](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302896/3.2+Status+and+EMR+Comments)
- [3.3 Financial Planning Targets](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302894/3.3+Financial+Planning+Targets)
- [3.4 Public Project Information](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302898/3.4+Public+Project+Information)
- [3.5 Quantities/Accomplishments](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302900/3.5+Quantities+Accomplishments)
- [3.6 Project Tender Details](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302902/3.6+Project+Tender+Details)

# 3.1 Project Details

Project details refers to header level project information that describe a project such as Project Number, Project Name, Project Description etc.

## Getting to Project details

- Refer to [Navigation → Project Information](https://moti-imb.atlassian.net/wiki/display/CRPDB/2+Application+components#id-2Applicationcomponents-ProjectInformation) to see how to navigate to various sections of the application.

## Edit project details

- To edit project details click on the edit button on the top right corner of this section. This would open the edit form, where the user can update and save (Submit) the project information.

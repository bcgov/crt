# 3 Project data entry

## New Project

Users can create project via the *Add Project* button on the project search screen.

<!-- IMAGE: Add Project button on search screen -->

Then provide the relevant details on the *Add Project* form that pops up. Some fields are required to create a new project.

<!-- IMAGE: Add Project form -->

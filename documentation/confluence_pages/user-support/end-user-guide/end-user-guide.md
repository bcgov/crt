# CRT End User's Guide

<!-- IMAGE: image2021-5-7_10-38-38.png - CRT End User's Guide cover image -->

| Document Version | Update Description | Update Date | Update By |

These pages are intended to provide users an overview to help gain familiarity with features of the CaRT/CRT application.

## How this guide is organized

Files in this folder are prefixed with their section number so a directory listing matches the intended reading order. Each file's `source:` frontmatter links back to the original Confluence page for traceability.

Recommended reading order for newcomers:

1. **Start here:** [01-using-this-guide.md](01-using-this-guide.md) — terminology and how to access the application.
2. **Orientation:** [02-application-components.md](02-application-components.md) — environments, navigation, search, common UI actions.
3. **Day-to-day workflows:** [03-project-data-entry.md](03.0-project-data-entry.md) and its subsections (3.1 – 3.8) — creating and maintaining project records.
4. **Administrator workflows:** [04-administration.md](04.0-administration.md) and its subsections (4.1 – 4.4) — users, roles, code tables, elements.
5. **Reporting:** [05-reports-and-dashboards.md](05-reports-and-dashboards.md) — exporting data and PowerBI reports.

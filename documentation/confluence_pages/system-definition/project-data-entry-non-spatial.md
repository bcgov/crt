## Goals (functions/sub-features)

| # | Goal / Function | Description | Story | Importance |
|---|----------------|-------------|-------|------------|
| 1 | Add projects and status data | Users need to be able to add projects and submit associated data describing them and their status. [Project details and status](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302684) | CRPDB-49 | High |
| 2 | Add Financial planning/Accomplishment details | Users should be able to provide financial and accomplishment details (planned and actual). [Planning and Accomplishment](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302688) | CRPDB-50, CRPDB-53 | High |
| 3 | Add tender information | User should be able to provide details about project tender. [Tender Information](https://moti-imb.atlassian.net/wiki/spaces/CRPDB/pages/102302691) | CRPDB-56 | High |
| 4 | View and edit provided information | User should be able to see the list of projects, as well as various pieces of information for each of project and, when applicable, edit the project information | CRPDB-48 | High |
| 5 | Log changes made by the user | Every time a new piece of information is added or existing data is changed, the action needs to be logged (to be made available as a report for later feature) | Incorporated in DB design | High |

# System Access

### Integrated Authentication

All users must have a valid TRAN IDIR account and use the KeyCloak login.

### Information Access Restricted through Roles

Information access should be restricted based on the roles defined during implementation. Roles should be able to view classifications for each role and have a strong understanding of their level of information access ability.

### Audits and Logging

The Solution should have logging and auditing capabilities including the ability to audit history. An audit function should identify when information is used in an abnormal manner, such as access attempts made on information that is beyond a user's role or other abnormal behavior such as repeated searches over long periods of time. Logging and flagging of abnormal behavior is needed to prevent misuse of information.

### Super User

A super user (or super administrator) should have the ability to restrict access of information based on role but also based on individuals.

### Ability to Detect Intrusion Efforts

*All intrusions are logged using current Ministry logging standards and are available to authorized IMB staff for viewing purposes.*

# Planning and Accomplishment

This page documents the input field properties for Financial Planning Targets and Quantities/Accomplishments screens.

## Field properties

### Filters

Filter fields used to narrow financial planning and accomplishment data.

### Financial Planning Targets

Detailed field specifications for financial planning target entry including DB column mappings, types, mandatory flags, and validation rules.

### Quantities/Accomplishments

Detailed field specifications for quantity and accomplishment data entry.

## Lists

The following code lookups are used:

- **Fiscal Year** (CODE_LOOKUP - CODE_SET = 'FY')
- **Phase** (CODE_LOOKUP - CODE_SET = 'PHASE')
- **Forecast Type** (CODE_LOOKUP - CODE_SET = 'FORECAST_TYPE')
- **Quantity** (CODE_LOOKUP - CODE_SET = 'QUANTITY')
- **Accomplishment** (CODE_LOOKUP - CODE_SET = 'ACCOMPLISHMENT')
- **Elements** - Hierarchical association of programs, service lines, and activity codes

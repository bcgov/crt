# Segments and Ratios

This page documents the input field properties for Project Segments and Ratios screens.

## Field properties

### Project Segments

Detailed field specifications for segment data entry including highway, start/end coordinates, landmarks, and lengths with DB column mappings.

### Ratios

Field specifications for ratio calculations across administrative boundaries (electoral districts, economic regions, service areas, districts).

## Lists

- **Electoral District** - Provincial electoral district boundaries
- **Highway** - Highway reference data
- **Economic Region** - Economic region boundaries

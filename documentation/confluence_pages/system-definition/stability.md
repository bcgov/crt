# Stability

### Performance Stability

System performance should be maintained over time. As usage, data storage and traffic increases, performance should remain consistent and be able to meet minimum acceptable levels of performance. This includes both the current system design and any new functionality that is added in the future.

### Information Integrity

System must maintain the integrity of the information over long periods of time up to an including data during the entire length of a contract (10+ years). Corruption or loss of data should not be possible.

### Recovery

The application is not deemed critical and doesn't need to be highly available. In the event of failures, downtime or restarts, there should be measures in place to minimize the negative impact to the system and the application should be made available within an acceptable time frame (no longer than 4 weeks).

# Project Glossary

| Abbreviation/Term | Also Known As | Expanded form | Description |
|---|---|---|---|
| CaRT | CRT/CRPDB/RPTDB | Capital and Rehabilitation Projects Tracking Database | Reference to this project/reporting tool used for rehabilitation project tracking |
| MoTI | The ministry | Ministry of Transportation and Infrastructure | Refers to this ministry within the Government of British Columbia. |
| IMB | | Information Management Branch | Refers to the branch of MoTI that works on delivering and maintaining the Information Technology services. |
| CAS | CAS-ORCA | Chart of Accounts system | Financial accounting system used to track expenditure, as invoices are paid |
| PIP | | Preservation Investment Plan | Long term investment plan that influences the budget allocation of preservation program projects |
| DB | | Database | Data storage for the application |
| Legacy | Access DB | Capital Rehab Program Data | Refers to the Access DB and SharePoint solution used by the business area prior to CRT |

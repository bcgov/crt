## Summary

Initial release for Capital and Rehabilitation Tracking Project, to replace the legacy solution.

## Important highlights from this release

- Replace current access DB with the new supportable solution
- Provide users the means to provide project data - fitting the business' planning and reporting needs
  - Includes project details, financial planning, tender details, qty and accomplishments, project segments and ratios.
  - Auto determination of ratios - using segment information to suggest various ratios, these still need to be validated by the users but should make data entry easier.
- Migrate legacy data from the access database to the CaRT system
- Provide means to access the data and build reports - through Power BI (Business Intelligence) report server.

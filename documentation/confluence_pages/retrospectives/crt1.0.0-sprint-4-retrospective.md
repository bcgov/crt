# CRT1.0.0 Sprint 4 Retrospective

## What did we do well?

- While Young-Jin had to focus on the map implementation the rest of the team picked up and shared load nicely.
- Team has continued to work and communicate well, and generally the results of the sprint are in line with the expectation.
- Testing is going well, the tickets are being handled with short turnaround, it's very agile.
- Kudos to developers to insert the map to the OpenShift environment.
- User participation has been great which has been helpful in making improvements and corrections.

## What should we have done better?

- The sprint objective was a bit more than originally expected.
- Resources have had more distractions (operational needs) that need to be better incorporated.
- Need to better determine changes to sprint priorities when resource allocation changes.

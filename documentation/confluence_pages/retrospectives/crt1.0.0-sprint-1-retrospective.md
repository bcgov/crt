# CRT1.0.0 Sprint 1 Retrospective

| Field | Value |
|---|---|
| Date | Jan 19, 2021 |
| Participants | Devashish Bhargava, Young-Jin Chung, Peter Spry, Peter DeWith, Darrel Siegle, Samantha Griffore |

## What did we do well?

- Team worked well together
- Team communication has been good, so far
- Young-Jin helped in picking up some of the work from Darrel while he was utilized partially on HMCR.
- Wireframes were helpful for the UI design
- Team members new to agile approach are thrilled to be working on the Agile project, and can see the difference from traditional approaches.
- Great support from business in terms of participation, availability to answer queries.

## What should we have done better?

- DB for sprint one was a bit of a bottleneck, work on giving DBA more time before the sprint starts so as to give them sufficient time, and have the physical DB ready for the start of the subsequent sprint. Lesson learnt - include DBA team in earlier project discussions before final project team is identified.
- Rough start in terms of artifacts that could have helped DB team to gain business side understanding, most of it had to be learnt as we moved through the sprint 1. This can be improved upon with sufficient headway and incrementally building the DB for sprints, moving forward.
- Darrel is slightly utilized on HMCR as well, at this point this is not an issue but can be a concern if there is more work coming in from CRT
- Some rework required on the UI while connecting with the back-end as some guesswork had to be done regarding field names
- We did not have fire wall rules in place which has delayed set up for Test environment.

## Actions

- [x] Set up DB design sessions slightly before the sprint starts
- [x] Set up some form of a dashboard to see real time progress
- [x] Follow up with Tech OPS for firewall rules

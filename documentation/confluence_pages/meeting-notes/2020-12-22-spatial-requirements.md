## Goals

- Identify current spatial needs from rehab and regional spatial team's standpoint

- Identify alignments of spatial needs/areas for improvement with the current CRT development.

## Discussion items

- At the moment when coordinates are entered users can only check the location for the start coordinates on the map, and not for the end coordinates. This makes using the end coordinate for spatial reporting difficult and therefore only start coordinates are used, so at the moment linear most projects are depicted through a single point.
- Being able to validate start and end points, by dropping a pin or checking coordinates on the map, and recording the underlying geometry (linear) should greatly benefit the spatial team from a reporting standpoint.
- At this point only one set of start and end coordinates can be entered for a project, this is not fully representative of all projects. Many projects may have multiple segments which would be represented by multiple sets of start and end locations (segments).
  - Consider the ability to add multiple segments for a project
  - For the geometry we can use CHRIS RFI or ITN
- It would greatly benefit the team's data entry process if the ratios section can be auto populated using the segments, while letting the users make updates and corrections where necessary.
